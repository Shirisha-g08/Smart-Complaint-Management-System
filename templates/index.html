Key Features

Everything you need for efficient complaint resolution

Easy Submission

File a complaint in seconds — title, description, and category. Stored securely in AWS DynamoDB.

Real-time Tracking

Monitor your complaint from Pending → In Progress → Resolved with full transparency.

SNS Notifications

Receive email/SMS alerts via AWS SNS whenever your complaint is submitted or its status changes.

Admin Dashboard

Admins see all complaints, update status, and add resolution remarks — all from one clean dashboard.

Secure by Design

Role-based access (User / Admin), bcrypt-hashed passwords, and AWS IAM policies protect every layer.

Cloud Scalable

DynamoDB on-demand billing scales automatically. EC2 Auto Scaling handles traffic spikes effortlessly.
